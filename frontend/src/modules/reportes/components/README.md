# modules/reportes/components — gráficos de indicadores

Gráficos hechos con vistas de React Native (sin librería de gráficos), así se ven igual en la web y en el celular. Son los mismos gráficos que lleva el reporte PDF.

## Archivos

- [GraficoBarras.tsx](GraficoBarras.tsx): barras horizontales con etiqueta, valor y detalle opcional (por empresa, área y prioridad).
- [BarraEstados.tsx](BarraEstados.tsx): una barra dividida por estado, con leyenda y porcentajes.
- [GraficoMensual.tsx](GraficoMensual.tsx): columnas por mes con tickets creados y cerrados.
