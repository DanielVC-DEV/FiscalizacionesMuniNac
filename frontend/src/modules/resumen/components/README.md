# modules/resumen/components

Piezas de la pantalla de resumen.

- [ResumenPanel.tsx](ResumenPanel.tsx): contenido completo del resumen (indicadores, buscador y filas por estado).
- [Stat.tsx](Stat.tsx): indicador (número + etiqueta) de la fila "Requiere atención".
- [FilaEstado.tsx](FilaEstado.tsx): fila desplegable de un estado con sus tickets y acceso al detalle de cada uno.

Volver al [README del módulo resumen](../README.md).
