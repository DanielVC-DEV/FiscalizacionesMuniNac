# modules/menu/components

Componentes usados sólo por el menú.

- [BarraLateral.tsx](BarraLateral.tsx): menú lateral izquierdo de la web.
- [MenuLateralMovil.tsx](MenuLateralMovil.tsx): la misma barra como panel deslizable para el celular y ventanas angostas, con fondo oscuro. Lo abre el botón de tres barras de [SesionHeader](../../auth/components/SesionHeader.tsx).
- [IconosMenu.tsx](IconosMenu.tsx): íconos decorativos de cada tile. No usan librería de íconos para no sumar dependencias nativas.
